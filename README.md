# QuantumDisasters

마인크래프트 **Paper 26.3** 플러그인. 게임이 시작되면 일정 간격으로 매번 **다른** 자연재해가 무작위로 찾아옵니다.

## 흐름

- `/qd start` 로 게임을 시작하면 **DAY 1** 부터 날짜를 셉니다. 액션바에 `DAY n` 이 표시됩니다.
- `disaster-change-days` 일마다 직전과 **다른** 재해로 바뀝니다.
- 그 기간 동안은 같은 재해가 휴식 시간을 사이에 두고 반복해서 찾아옵니다. (`interval-seconds: 0` 이면 쉬지 않고 계속)
- `survive-days` 일을 버티면 **성공**, 리스폰 모드가 `unlimited` 가 아닐 때 모두 죽거나 탈락하면 **게임 오버**입니다.

재해가 처음 시작되거나 다른 재해로 바뀔 때는 **사이렌**이 울립니다. (이름은 알려주지 않고 바뀌었다는 것만 알 수 있음, 같은 재해가 반복될 때는 울리지 않음)

플레이어에게는 **어떤 재해인지 이름을 알려주지 않습니다.** (보스바·타이틀은 "재해 진행 중" 처럼만 표시, 관리자 명령어 `status`/`list`/`trigger` 에서만 보임)
채팅 안내는 게임 시작·종료·성공·게임 오버, 목숨(남은 목숨, 탈락), 부활에 대해서만 보냅니다. 재해가 오고 가는 것과 피폭 증상은 채팅으로 알려주지 않습니다.

보스바에 다음 재해까지 남은 시간 / 재해 남은 시간이 표시되고, 재해 직전에 경고 카운트다운이 뜹니다.

## 리스폰 모드 (`respawn.mode`)

| 모드 | 설명 |
|---|---|
| `unlimited` | 죽어도 계속 리스폰 |
| `lives` | `respawn.lives` 개수만큼만 리스폰, 다 쓰면 탈락(관전 모드) |
| `after-disaster` | 재해 중에 죽으면 관전하다가 그 재해가 끝나면 부활 |

| `avalanche` | 눈사태 | 근처 높은 곳에서 눈과 가루눈 덩어리가 9초마다 쏟아져 내려옴. 맞으면 밀려나고 얼어붙으며, 쌓인 눈·가루눈에 파묻힘 | 옆으로 피하기 |
| `sandstorm` | 모래 폭풍 | 바깥은 앞이 거의 안 보이고 바람에 떠밀림. 투구 없으면 모래에 긁혀 피해. 땅이 모래로 덮이고 풀이 말라 죽음 | 실내 / 투구 |
| `blizzard` | 눈보라 | 바깥이면 얼어붙고 크게 느려짐. 반경 30칸에 눈이 계속 쌓이고 물이 얼음으로 | 실내 / 가죽 갑옷 |

### 태양 입자 폭풍과 가이거 계수기

- 방사선은 빠르게 치솟았다가 반감기(매번 60~180초 무작위)에 따라 천천히 줄어들고, 중간에 다시 치솟기도 합니다. 그래서 시간만 재서는 언제 끝날지 알 수 없습니다. (보통 7~15분)
- 내가 있는 곳의 방사선은 **머리 위 블록**에 따라 줄어듭니다. 수직 + 비스듬한 4방향으로 계산해서, 벙커 깊은 곳은 거의 0 이고 입구·창문 근처는 새어 들어옵니다. 돌·흙·물이 잘 막고 유리·나뭇잎은 거의 못 막습니다. 높은 곳일수록 강합니다.
- 맞은 방사선은 **피폭량**으로 쌓이고 1분에 1 mSv 씩 아주 천천히 줄어듭니다. 쌓일수록 허기 → 나약함 → 채굴 피로·메스꺼움 → 피해 → 큰 피해. (채팅 안내 없이 증상만 나타남)
- **가이거 계수기**: 손(주 손/보조 손)에 들고 있으면 지금 위치의 방사선에 맞춰 딸깍 소리가 불규칙하게 납니다. 숫자는 보여주지 않습니다. (평소 1초 0.5번 → 폭풍 절정에 밖에서 1초 30번 이상)
- 기본 제작법 (설정에서 변경 가능):
  ```
   R      R = 레드스톤
  CGC     C = 구리 주괴, G = 유리판
  CIC     I = 철 주괴
  ```

### 지진과 지각판

월드 시드로 지각판 지도가 정해집니다 (같은 시드면 항상 같은 지도). 판마다 움직이는 방향이 있고, 맞닿은 두 판의 움직임에 따라 경계 종류가 정해집니다.
지진이 오면 플레이어마다 가장 가까운 판 경계가 진원이 됩니다.

| 경계 | 두 판의 움직임 | 지진 때 일어나는 일 |
|---|---|---|
| 발산형 | 서로 멀어짐 | 경계를 따라 땅이 벌어지며 깊게 갈라짐 (점점 넓어짐), 바닥에 용암·마그마 |
| 수렴형 | 서로 부딪힘 | 경계를 따라 땅이 솟아 능선이 생김 (지진이 반복되면 점점 높아짐), 바위가 굴러떨어짐, 위아래로 가장 세게 흔들림 |
| 보존형 | 옆으로 엇갈림 | 경계 건너편 땅이 경계를 따라 2~3칸 옆으로 어긋남 + 얕은 단층선, 경계와 나란한 방향으로 흔들림 |

관리자는 `/qd plate` 로 지금 위치의 판·가장 가까운 경계(종류, 거리, 방향)를 볼 수 있고, `/qd plate show` 로 10초 동안 경계선을 색깔 입자로 표시할 수 있습니다. (빨강 = 발산형, 파랑 = 수렴형, 초록 = 보존형)

모든 수치는 `config.yml` 에서 재해별로 바꿀 수 있고, `intensity` 로 전체 세기를 한 번에 조절할 수 있습니다.
`block-damage: false` 로 하면 지형은 바뀌지 않습니다. (지형 변화는 되돌아가지 않음)
홍수·쓰나미의 물과 화재의 불은 재해가 끝나면 원래대로 되돌아갑니다. (되돌리는 도중 서버가 꺼져도 바로 마무리)

서바이벌·모험 모드 플레이어만 영향을 받습니다. (크리에이티브·관전자 제외)

## 명령어 (권한 `quantumdisasters.admin`, 기본 OP)

`/quantumdisasters`, `/qd`, `/disasters` 모두 같은 명령어입니다.

| 명령어 | 설명 |
|---|---|
| `/qd start` | 게임 시작 |
| `/qd stop` | 게임 종료 (진행 중인 재해 정리, 날씨 복구) |
| `/qd skip` | 현재 단계 건너뛰기 |
| `/qd trigger <id>` | 특정 재해 즉시 발생 |
| `/qd list` | 재해 목록 |
| `/qd status` | 현재 상태 |
| `/qd players` | 플레이어 목록 (Java/Bedrock, 목숨) |
| `/qd plate [show]` | 지금 위치의 지각판·경계 정보 (show: 경계선 표시) |
| `/qd give geiger [플레이어]` | 가이거 계수기 지급 |
| `/qd dose` | 접속자 피폭량 + 계수기 제작법 확인 |
| `/qd siren` | 사이렌 테스트 (모든 접속자에게 들림) |
| `/qd reload` | config.yml 다시 불러오기 |

## 설정 (`plugins/QuantumDisasters/config.yml`)

| 항목 | 기본값 | 설명 |
|---|---|---|
| `auto-start` | `false` | 서버가 켜지면 자동 시작 |
| `day-length-seconds` | `1200` | 하루 길이(초). 마인크래프트 하루 = 1200초 |
| `sync-world-time` | `true` | 새 날마다 월드 시간을 아침으로 맞춤 |
| `disaster-change-days` | `1` | 몇 일마다 재해가 바뀌는지 |
| `survive-days` | `10` | 몇 일을 버티면 성공인지 (0 = 무한) |
| `respawn.mode` | `lives` | `unlimited` / `lives` / `after-disaster` |
| `respawn.lives` | `3` | 목숨 개수 (`lives` 모드) |
| `first-delay-seconds` | `15` | 첫 재해까지 대기 시간 |
| `interval-seconds` | `45` | 재해 사이 휴식 시간 (0 = 쉬지 않음) |
| `warning-seconds` | `5` | 경고 카운트다운 |
| `siren.sound` | 디저리두 + 플루트 | 사이렌 소리 (목록으로 쓰면 겹쳐 재생, 리소스팩 커스텀 소리 가능) |
| `siren.min-pitch` / `max-pitch` | `0.5` / `1.3` | 음 높이 범위 (0.5~2.0, 낮을수록 어두움) |
| `siren.rise-ticks` / `hold-ticks` / `fall-ticks` | `60` / `30` / `100` | 올라가는 / 버티는 / 내려가는 시간(틱) |
| `siren.cycles` / `interval-ticks` / `volume` | `1` / `1` / `1.0` | 반복 횟수, 소리 간격(틱), 음량 |
| `siren.wobble` / `wobble-ticks` | `0.4` / `24` | 회전하는 경보기처럼 크기가 흔들리는 정도·주기 |
| `siren.detune` | `1.06` | 살짝 어긋난 음을 겹침 (1 이면 끔) |
| `bedrock.knockback-multiplier` | `0.7` | Bedrock 플레이어를 밀어내는 세기 배율 |
| `intensity` | `1.0` | 전체 재해 세기 배율 (운석 수, 벼락 수, 부서지는 블록 수 등) |
| `block-damage` | `true` | 재해가 블록을 부술지 여부 |
| `worlds` | `[]` | 재해가 일어날 월드 (비우면 전체) |
| `disasters.<id>.enabled` / `duration-seconds` | | 재해별 켜기·끄기, 한 번의 지속 시간 |

## 크로스플랫폼 (GeyserMC)

[Geyser](https://geysermc.org) + Floodgate 와 함께 써서 Bedrock(모바일·콘솔·Windows) 플레이어도 참여하는 것을 목표로 합니다.

- 화면 표시는 Bedrock 에서도 보이는 것만 사용합니다: 액션바, 타이틀, 보스바, 채팅
- 재해 이름에 이모지/특수 기호를 쓰지 않습니다 (Bedrock 글꼴에서 네모로 깨질 수 있음)
- Floodgate 가 있으면 Bedrock 플레이어를 구분합니다 (`softdepend`, 없어도 동작)
  - `/qd players` 로 Java/Bedrock(기기), 목숨 상태 확인
  - 지진·토네이도가 Bedrock 플레이어를 밀어내는 세기를 `bedrock.knockback-multiplier`(기본 0.7)로 약하게
- 플레이어는 UUID 로 관리하므로 Floodgate 플레이어(이름 앞 `.` 등)도 목숨·부활이 정상 동작합니다
- 새 재해를 추가할 때도 위 규칙을 지켜주세요

## 빌드

Java 25 와 Maven 이 필요합니다.

```bash
mvn package
```

`target/QuantumDisasters-1.0.0.jar` 를 서버의 `plugins/` 폴더에 넣으세요.

## 다른 플러그인에서 게임 시작하기

```java
QuantumDisasters qd = (QuantumDisasters) Bukkit.getPluginManager().getPlugin("QuantumDisasters");
qd.disasterManager().start(); // 게임 시작 시
qd.disasterManager().stop();  // 게임 종료 시
```
